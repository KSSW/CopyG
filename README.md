# How Use？
# Step 1:

Open CopyG, Write File Path\Example: 
```bash
A:\BDMV\STREAM\00000.m2ts
A:\BDMV\BACKUP\PLAYLIST\00000.mpls
A:\BDMV\BACKUP\CLIPINF\00000.clpi
A:\BDMV\BACKUP\index.bdmv
A:\BDMV\BACKUP\MovieObject.bdmv
D:\BD\AMB_MOVIE\META\TEST\BDMV\META\DL\bdmt_eng.xml
D:\BD\AMB_MOVIE\META\TEST\BDMV\META\DL\bdmt_zho.xml
D:\BD\AMB_MOVIE\META\TEST\BDMV\META\DL\Large_Metadata640.jpg
D:\BD\AMB_MOVIE\META\TEST\BDMV\META\DL\Small_Metadata416.jpg
A:\BDMV\CLIPINF\00000.clpi
A:\BDMV\PLAYLIST\00000.mpls
A:\BDMV\index.bdmv
A:\BDMV\MovieObject.bdmv
A:\CERTIFICATE\BACKUP\id.bdmv
A:\CERTIFICATE\id.bdmv
```
Note: When copying the META folder, the META folder must be BDMV file structure complete (Incomplete Will not copy Files in META folder).

# Step 2:

Click Copy Start...\
When the copy is complete，Automatic hashing of copied files.
